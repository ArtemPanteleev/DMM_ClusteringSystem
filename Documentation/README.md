# Документация проекта DMM Clustering System

Директория `Documentation/` является централизованным хранилищем всей текстовой документации проекта. Здесь собраны материалы для разработчиков, пользователей и исследователей, работающих с системой кластеризации.

## Назначение

Документация в проекте выполняет следующие функции:

- **Онбординг новых разработчиков** — быстрый старт работы с кодом
- **Справочная информация** — описание архитектуры, методов кластеризации
- **Инструкции** — пошаговые руководства по использованию и расширению системы
- **История разработки** — описание изменений по фазам проекта
- **Теоретическая база** — материалы по алгоритмам кластеризации

## Структура директории

```
Documentation/
├── Programming documentation/    # Программная документация
├── Theoretical documentation/    # Теоретическая документация
└── Developer notes/              # Заметки разработчиков
```

---

## Programming documentation/

**Содержимое:** Программная документация, руководства для разработчиков, диаграммы архитектуры, примеры использования.

**Аудитория:** Разработчики, студенты, работающие над проектом.

**Когда обращаться:**
- При добавлении нового метода кластеризации
- При изучении архитектуры системы
- При необходимости понять логику работы компонентов

### Основные файлы:

- **`Как добавить новый метод кластеризации.md`** — пошаговая инструкция по интеграции нового алгоритма в систему через паттерн Strategy
- **`developer's guide.docx`** — полное руководство разработчика (версия v2)
- **`UsesCases.md`** — примеры использования системы с описанием сценариев работы (версия v2)
- **`UMLv2.5 - Project diagram.vsdx`** — диаграмма компонентов UML (открывается в Microsoft Visio, устарела)
- **`Research/`** — исследовательские материалы по процессу кластеризации с использованием разработанного ПО
  - `Research.pdf`, `Research.docx` — исследовательские работы
  - `README.MD` — описание содержимого раздела
- **`docs_images/`** — изображения для документации (диаграммы use cases, скриншоты)

## Theoretical documentation/

**Содержимое:** Теоретические материалы по алгоритмам кластеризации в формате PDF.

**Аудитория:** Исследователи, студенты, изучающие алгоритмы кластеризации.

**Когда обращаться:**
- При изучении математических основ алгоритмов
- При необходимости понять принципы работы конкретного метода
- При подготовке презентаций или докладов
- При написании научных работ

### Доступные материалы:

- **BANG.pdf** — алгоритм BANG (Bounding And Nesting Grid)
- **birch.pdf** — алгоритм BIRCH
- **cure.pdf** — алгоритм CURE
- **DBSCAN.pdf** — алгоритм DBSCAN
- **FCM-the_Fuzzy_C-Means_clustering-algorithm.pdf** — Fuzzy C-Means
- **GMM clustering.pdf** — Gaussian Mixture Model
- **HDBSCAN.pdf** — Hierarchical DBSCAN
- **OPTICS.pdf** — алгоритм OPTICS
- **rock.pdf**, **Rock - presentation.pdf** — алгоритм ROCK
- **Spectral Biclustering.pdf** — Spectral Biclustering

**Источники:** Документация из scikit-learn и pyclustering, научные статьи и презентации.

### Где искать информацию по темам:

| Тема | Где искать |
|------|------------|
| **Архитектура системы** | `Programming documentation/developer's guide.docx`<br>`Programming documentation/UMLv2.5 - Project diagram.vsdx` |
| **Методы кластеризации** | `../ClusteringMethods/README.md`<br>`Theoretical documentation/*.pdf` |
| **Добавление нового метода** | `Programming documentation/Как добавить новый метод кластеризации.md` |
| **Примеры использования** | `Programming documentation/UsesCases.md`<br>`../README.md` (раздел "Примеры использования") |
| **Инструкции по запуску** | `../README.md` (раздел "Запуск проекта")<br>`../BUILD.md` |
| **Фазы разработки** | `Developer notes/phase4.md` |
| **Теоретические основы алгоритмов** | `Theoretical documentation/*.pdf` |
| **Исследовательские материалы** | `Programming documentation/Research/` |

### Быстрый старт для разработчиков:

1. **Новый разработчик:**
   - Начните с `../README.md` — общее описание проекта
   - Изучите `Programming documentation/developer's guide.docx` — архитектура системы
   - Прочитайте `Programming documentation/Как добавить новый метод кластеризации.md` — как расширять систему

2. **Добавление нового метода:**
   - `Programming documentation/Как добавить новый метод кластеризации.md` — инструкция
   - `../ClusteringMethods/README.md` — примеры существующих методов
   - `Theoretical documentation/` — теоретические материалы по алгоритму

3. **Изучение алгоритма:**
   - `Theoretical documentation/[algorithm].pdf` — теория
   - `../ClusteringMethods/README.md` — описание реализации в проекте
   - `../TestMethods/` — примеры использования и тесты
